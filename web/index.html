Install

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer to install.

  1. Plug the board into your computer with a USB cable that carries data (some charge-only cables don't).
  2. Choose your board below and click Install. Pick the serial port that appears. If none appears on Windows, install the CH340 USB driver and try again. ESP32-S3 boards need no driver; if no port appears, hold the BOOT key while plugging the board in.
  3. Wait for "Installation complete", then press the board's reset button (or unplug and replug it).

Which board do I have?

Boards are told apart by chip (when it isn't the plain ESP32), screen size, display driver and touch type. Check the text printed on the back of the board.

After installing

  • Touch calibration runs on first start on resistive boards: tap the tip of each corner arrow. To redo it later, hold the BOOT button while powering on. Capacitive boards need no calibration.
  • Colors look wrong? Tap Invert if the background is light or colors look like a negative, and Swap R/B if the red and blue bars are swapped. The board remembers the fix.
  • Blank or garbled screen on a 2.8" board? It probably has the other display driver. Install the other 2.8" version.
